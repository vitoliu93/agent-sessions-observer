# Goal: 控制台 UI 重设计

**Created**: 2026-09-18  **Tier**: full

## Intent
精简无关信息，定义统一风格，去掉过多装饰。让用户先看清目标、解决路径和未解决问题。引入 Tailwind CSS 与图标库，简化前端代码。

## 参考真源
- `src/web/`：现有界面和交互范围。
- `docs/design/astra-review-v2.md`：需求解决地图、署名、证据和未知的业务边界。
- `docs/design/mock-v2.html`：样稿数据来源，不能当作当前会话事实。
- 本目录 `prototype.html`：待用户确认的视觉与交互样稿。正式实现与批准版本逐项、逐屏对照。
- `tests/web/`：地图、详情、历史、轮询的既有行为测试。

## Done means
- 用户确认样稿的风格和信息取舍后，正式页面按样稿实现。
- 首屏不再铺开参与者标签、两行时间戳和重复的说明、操作提示；次要信息仍能打开查看。
- 风险、失败、范围有限、未知不被省略成成功；原有记录和关系不删除。
- 无渐变、发光、彩色卡片底；统一字级、细边线、小圆角；颜色只提示选中和状态。
- Tailwind CSS 参与正式开发与生产构建；使用图标组件，移除对应字符图标及重复布局样式。
- 构建、类型检查、单元测试及相关浏览器测试通过；1920、1280、900 像素宽度下页面无横向溢出，地图自身可横滚。

## Explicitly out of scope
- 不改数据解析、归纳模型、HTTP 契约或历史数据。
- 不把需求地图改成代理看板，不新增账号、云服务、成本统计或完成百分比。
- 不发布、不推送、不合并、不改用户现有服务。

## Scope changes (append-only)
- 无。

- 2026-09-18：用户明确要求“直接发布”。允许合并、推送 main，发布 npm 0.6.0 和对应版本标签；不改用户现有服务。发布以该提交的远端 CI、发布工作流和 npm 下载检查通过为准。
