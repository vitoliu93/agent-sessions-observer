# Spec: 控制台 UI 重设计

## 大前提
控制台服务于判断，不服务于展示指标。首屏只放目标、当前工作、待确认问题与解决路径；完整依据按需展开。

## 小前提
当前页面有多层横条、重复提示、多色徽章与渐变卡片。参与者、署名数量、子会话数量、两种时间戳同时争夺空间。地图顶部还留有 104px 的卡片起始距离。

保留：目标到结果的五列地图、动词连线、署名、完整事实、失败记录、分支、参与者筛选、历史回放、阅读中不替换地图、渐进生成。

## 结论

### 风格：纸面工作台
- 背景 `#f6f7f7`，卡片 `#ffffff`，正文 `#242a2b`，次级正文 `#60696a`，边线 `#dde2e1`。
- 单一强调色 `#2c6657`。风险用暗黄，失败用暗红。类型不再各配一套颜色。
- 系统字体。正文 13–14px，卡片标题 14px，区域标题 16px。不得靠缩小文字容纳内容。
- 6px 圆角，1px 边线；不加渐变、发光、网点背景、装饰性统计或大标语。
- 普通按钮不抢眼；图标 16px，同一套线条。纯图标按钮必须有可读名称。

### 信息取舍
| 位置 | 常显 | 按需显示 / 移除 |
| --- | --- | --- |
| 顶栏 | 产品名、会话切换、更新状态、同步 | 两种时间戳放同步详情；移除产品标签 |
| 进展 | 当前工作、仍需确认 | 完整三项进展进详情；移除三次“查看全文” |
| 地图工具栏 | 分支选择、必要时的重置、新摘要提示 | 参与者与历史变为入口；移除独立参与者横条 |
| 卡片 | 标题、一句事实、状态、署名、详情入口 | 完整事实/条件进详情；不显示“0 条问题”等无意义数字 |
| 地图 | 细灰连线、少量动词、选中路径 | 其他关系通过选择和详情读取；不按类型铺彩色底 |
| 系统说明 | 错误、不完整覆盖、生成中等影响判断的提示 | 普通技术说明收进同步详情，不丢失警告 |

### 实现范围（批准后）
- `src/web/components/`、`src/web/App.tsx`、`src/web/styles.css`：样式、布局、文案与可访问性。
- `src/web/lib.ts`：仅调整显示用颜色或文案，不改业务判断。
- `package.json`、`bun.lock`、前端构建入口：引入 Tailwind CSS 与 Lucide React。
- 使用 Tailwind 官方 CLI 编译样式，再由现有 Bun HTML 构建收集静态文件；不为样式更换 React 或引入 Vite。
- 开发命令须先生成 CSS，再监听 CSS/TSX；生产从干净目录能完整构建。不得依赖上一次残留文件。
- 动态地图坐标保留行内样式；普通布局、字号、边距改为 Tailwind 类；仅保留地图连线、动画和共享状态的必要 CSS。
- Lucide 具名导入；不引入整套图标的动态注册表。
- `README.md`、`docs/design/v0.3-prd.md`：明确新方案替代旧的“不引入 Tailwind 和 Lucide”约定。

### 样稿边界
`prototype.html` 完全离线，使用仓内旧设计示例，不连接本机会话或模型。样稿的切换、添加、移除、同步、错误恢复仅改变演示状态。所有区域有 `data-src`。正式依赖尚未引入。

### 风险与验证
- 内容精简不能隐藏失败或把局部结果说成完成：逐项比较详情与示例原文。
- 改样式可能影响卡片实测高度与连线：运行原有几何、折叠、定位测试。
- 历史、草稿和阅读保护不能只做外观：运行原有快照与轮询测试。
- 样稿可用不代表正式页面通过，分开记录验证结论。

### 技术依据
- [Tailwind 官方 CLI](https://tailwindcss.com/docs/installation/tailwind-cli)：扫描组件并生成静态 CSS。
- [Lucide React](https://lucide.dev/guide/react/getting-started)：具名导入 SVG 图标组件。
- [Bun HTML 构建](https://bun.sh/docs/bundler/html-static)：继续使用现有 HTML、TSX、CSS 打包入口。
