# 目标

验收上一轮实现，接手观察台质量改进。输入真实 coding agent 会话后，让用户从地图判断需求解决到哪一步、谁贡献了什么、还缺哪些证据。找出当前可观察的不足并修复，保留诚实边界。

## 完成意味着什么

- 上一轮必改逐条有独立复验结果，不采信作者自报。
- 长会话地图有清楚的解决路径，卡片与连线不挤掉关键信息；详情与署名可达。
- 初次加载、空会话、失败、切会话、同步中和重试都有正确反馈，不用等待一个永远不消失的遮罩。
- 地图、进展、时间戳与抽屉属于同一观察时点；历史不拿最新正文冒充旧记录。
- 子代理贡献不因压缩或匹配错误被丢弃、混名或冒认。
- 输入坏数据不会把旧的可用地图清空，也不会生成虚假成功。
- 有本地运行、真实输入、隔离边界样例、浏览器 DOM 与截图的证据；已知限制明确写出。
- 保持前端单文件、无运行时依赖；前端不超过接手基线 730 行，不靠难读的压行达标。
