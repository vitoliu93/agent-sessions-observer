# 验收规格

1. 卡片显示与折叠集合不相交，且并集覆盖当前时点全部有效卡；区域按稳定子目标 ID 归属，不靠可变标题猜测。
2. 默认展示目标、关键路径与缺口；选择卡只强调直接关系，方向可读，详情可定位被折叠目标；署名与贡献可通过键盘读取。
3. 1920×1080 无页面横向滚动；42 卡/16 代理/52 边样例首屏可判断；展开容许纵向滚动，不裁掉正文。
4. 无变化轮询不重建卡、夺焦或重排；新变化明确提示，历史阅读不自动跳回实时。
5. 每次成功摘要记录完整快照；历史保留当时标题、事实、署名、边、进展、覆盖度。未保存的旧历史明确不支持，不伪造。
6. 摘要失败保留上次成功地图及未消费文件变化；分析排队去重；API 的未知会话明确 404，不回退到另一个会话。
7. 模型输出校验类型、状态、ID 唯一、结构、边端点与动词；不随意推断完成或来源。子代理匹配不确定要报告而不是选一个冒充。
8. 测试使用隔离目录与假模型，不耗用真实模型预算；真实会话只读取证。用户现有 4173 服务不重启。
